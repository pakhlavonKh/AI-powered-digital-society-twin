# SocietyTwin: Python dependencies
#
# The implemented workbench and national pipeline declare their dependencies in pyproject.toml; the tested
# environment is pinned in requirements-api.lock (install that, not this file). The list below is the
# original PROPOSED stack; pyarrow, pydantic, fastapi and pytest are in use, the others are not yet.
#
# Target Python version: 3.12 (3.11 minimum), per the PROPOSED v2 architecture
# (docs/societytwin-v2-architecture.md, section 6.1). Dependencies will be
# declared with pinned versions in pyproject.toml when implementation starts.
#
# PROPOSED v2 Python stack:
#   - numpy                      vectorised population generation
#   - pandas                     reading and harmonising official tables
#   - pyarrow                    Parquet storage of population builds and results
#   - duckdb                     in-process queries on Parquet (cohorts, analysis)
#   - scipy                      distribution metrics (selectively)
#   - pydantic                   schemas, configurations, structured LLM outputs
#   - fastapi                    API layer
#   - a PostgreSQL driver        registry and job queue (SQLite for local tests)
#   - LLM provider SDK(s)        behind a provider-independent adapter (provider: OPEN DECISION)
#   - pytest, hypothesis         tests
#
# Not part of the MVP core: mesa (optional, small interaction experiments only).
